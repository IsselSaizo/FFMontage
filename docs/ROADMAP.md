# FF Montage — дорожная карта

Черновик от 29.10.2026. Подробности по каждой проблеме — в [AUDIT-0.3.md](AUDIT-0.3.md), ID вида `B-1`, `R-2` ведут туда.

**Схема:** хотфикс **0.3.1** → одно глобальное обновление **0.4.0** (этапы M0–M6, каждый этап — серия небольших PR) → патчи **0.4.x / 0.5.x**, причём основная часть новых функций приходит плагинами.

Размеры задач: **S** — до дня, **M** — 2–4 дня, **L** — 1–2 недели, **XL** — больше 2 недель (оценки ориентировочные, для одного разработчика).

Направления, по которым распределяются задачи:
- `RS` — Rust/бэкенд;
- `FE` — модель и логика фронтенда;
- `UI` — интерфейс и дизайн;
- `FF` — FFmpeg/экспорт;
- `QA` — тесты и платформы.

---

## Принцип «ядро и плагины»

**В ядре (фиксируется в 0.4):**
- модель проекта и миграции;
- таймлайн и инструменты монтажа;
- предпросмотр-композитор;
- сборщик экспорта;
- реестр действий и хоткеев;
- окно настроек;
- кэш;
- плагинный хост и его API;
- базовые эффекты и переходы, один шрифт, текст, субтитры.

**Плагинами:**
- пресеты эффектов, переходов, текстов и анимаций;
- шаблоны PiP и сеток;
- экспортные пресеты (ProRes/MXF и т.п. — как пресеты поверх ядра);
- аудиообработка;
- облака;
- распознавание речи;
- LUT;
- стабилизация;
- автонарезка по сценам;
- пресеты хоткеев сторонних монтажек (можно и в ядре — это просто JSON).

**Правило:** если функции нужен доступ к модели проекта, к таймлайну или к сборке графа FFmpeg на уровне, которого нет в API, сначала расширяем API ядра, затем пишем плагин. Встроенные эффекты и переходы тоже регистрируются через этот API как плагин `core`. Так API проверяется на реальной нагрузке.

**Вкладки сверху** (по-русски): **Видео** · **Аудио** · **Анимации**.
- **Видео** — монтаж, как сейчас.
- **Аудио** — внизу аудиодорожки таймлайна, справа стойка эффектов.
- **Анимации** — лёгкие анимации по пресетам.

**Правая панель остаётся**, из неё убираются дубли:
- вкладка «Эффекты» переименовывается в **«Фильтры»**;
- формат кадра и фон переезжают в панель над плеером;
- подсказки и таблица хоткеев уходят в настройки / справку.

**Панель над плеером — только иконки, без подписей:**
- Для клипа:
  - **Кадрирование** — включает режим: рамка с ручками в плеере, Enter применяет, Esc отменяет. Есть необязательная кнопка «применить такую же обрезку ко всем клипам этого файла».
  - **Подгонка** — вписать / заполнить / растянуть.
- Для проекта:
  - **Формат кадра**.
  - **Фон** — цвет, свой цвет, размытый кадр.
- Попапы открываются щелчком; там, где возможно, ещё и наведением. На тачскрине и Steam Deck — только щелчком. Кадрирование всегда открывается щелчком: это режим, а не попап.

**Скорость клипа ×0.1–×16:**
- настраивается в правой панели; появляется, когда выбран видео- или аудиоклип;
- чекбокс **«Сдвигать следующие клипы»**, по умолчанию выключен;
- тон звука сохраняется (`atempo`), замедление — повтором кадров;
- в предпросмотре скорость задаётся через `playbackRate`, запекать ничего не нужно (предел ×16 — ограничение `playbackRate` в Chromium).

**Аудио:**
- базовые эффекты — **эквалайзер, компрессор, шумодав**, остальное плагинами;
- эффект ставится на клип, если выбран клип, и на дорожку, если выбрана дорожка.

**Анимации:**
- пресет «Дождь»: картинка с прозрачностью, количество, скорость, разброс размеров, вращение, ветер, длительность, зацикливание, «случайность» (seed);
- «Сохранить» → видео с альфой в кэше → появляется в медиатеке;
- двойной щелчок по клипу снова открывает анимацию на правку;
- пока это **временная дорожка «Наложения»**, при переходе к нескольким видеодорожкам (M4) она уйдёт.

**Язык интерфейса:**
- перевод всего интерфейса на английский; язык переключается в настройках (задача M2.6);
- при первом запуске программа смотрит язык системы и раскладку (ru/en) и предлагает выбрать язык.

## Справочник FFmpeg (проверено на сборке n9.0.1)

| Задача | Рецепт |
|---|---|
| Маршрут в 8 каналов | `amerge=inputs=3,pan=8c\|c0=c0\|c1=c1\|c2=c2\|c4=c3\|c5=c4` → `pcm_s24le -ar 48000` |
| 8 моно-дорожек | `channelsplit` (из 7.1) или `asplit=8` + `pan=mono\|c0=cN`, затем 8 раз `-map` |
| ProRes MOV | `prores_ks -profile:v 2\|hq\|4444 -vendor apl0`; для 4444 — `-pix_fmt yuva444p10le -alpha_bits 16` |
| MXF OP1a | `dnxhd -profile:v dnxhr_hq -pix_fmt yuv422p -c:a pcm_s24le -timecode 10:00:00:00 -f mxf`. XDCAM: `setfield=tff` + `mpeg2video` 50M 4:2:2 |
| MKV | несколько аудиодорожек (aac/opus/flac/pcm) + субтитры srt/ass с `-metadata:s:a:N title=` |
| PiP | `setpts=PTS-STARTPTS+T/TB,scale…[p];[base][p]overlay=x:y:enable='between(t,a,b)':eof_action=pass` |
| Сетка 2×2 | `xstack=inputs=4:layout=0_0\|w0_0\|0_h0\|w0_h0` |
| Субтитры | `subtitles=filename='F\:/…srt':force_style=…` / `ass=…:fontsdir='<папка шрифтов проекта>'`; мягкие — `mov_text` в MP4 |
| Громкость | `loudnorm` в 2 прохода (`print_format=json` → `measured_*`, `linear=true`) |
| Анализ | `ebur128=peak=true`, `astats`, `scdet=threshold=10`, `afftdn=nr=12:nf=-40` |
